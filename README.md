# 🛰️ CINE-NAVIGATOR // HUD Cinema OS & Autonomous App

**CINE-NAVIGATOR** — это высокотехнологичная интерактивная медиа-система и умный каталог кинематографа, разработанный на чистом фронтенде без использования тяжелых бэкенд-серверов. Интерфейс выполнен в стиле футуристической HUD-панели управления (киберпанк / авиационные приборы) с кастомной неоновой визуализацией, шейдерной графикой и полной мобильной оптимизацией.

Страница проекта развернута на **GitHub Pages** и полностью переведена на рельсы автономного **PWA-приложения**.

---

## ⚡ Главные фичи и технический стек проекта

### 1. 🌌 WebGL Core & Шейдерная графика (`nebula.js`)
* **Технология:** Низкоуровневый графический API WebGL (`gl.drawArrays`, `gl.uniform1f`).
* **Суть:** Вместо статичного заднего фона на сайте в реальном времени рендерится живая, плавная неоновая туманность (космический газ). 
* **Оптимизация (Retina & Mobile):** Интегрирован автоматический расчет `pixelRatio`. На Retina-дисплеях (Mac M1-M5) разрешение шейдера аппаратно ограничивается для исключения фризов графики, а на мобильных устройствах (iPhone 12/13/14) разрешение плавно масштабируется в 2 раза для экономии RAM и CPU. Сайт выдает стабильные **60+ FPS**.

### 2. 🛰️ Навигационный Космический Радар (`radar.js`)
* **Технология:** HTML5 Canvas API, математическое проецирование координат.
* **Суть:** Вкладка каталога поддерживает бесшовное переключение в режим интерактивного Радара. Скрипт анализирует всю базу из 202 фильмов и распределяет их в виде светящихся неоновых звезд на координатной сетке неба: ось **X** отвечает за год выпуска, ось **Y** — за рейтинг IMDb. При наведении мыши или тапе пальцем плавно всплывают неоновые HUD-подсказки с метаданными фильма.

### 3. 📱 Полная PWA-Автономия (`manifest.json`, `service-worker.js`)
* **Технология:** Progressive Web App, Service Workers, Cache Storage API.
* **Суть:** Сайт полностью независим от наличия интернета. Браузер определяет его как нативное приложение. 
* **Результат:** На ПК появляется кнопка установки в адресной строке, а на iPhone через Safari приложение добавляется на экран «Домой» с кастомной неоновой иконкой. Приложение открывается во весь экран без рамок браузера, обтекая «челку» смартфона, и мгновенно работает в авиарежиме в небе.

### 4. 🧠 Смарт-фильтрация и ИИ-модули (`script.js`, `cinema-extras.js`)
* **Infinite Scroll (Бесконечный скролл):** Для защиты оперативной памяти мобильных процессоров каталог на 202 фильма рендерится порциями (сначала 24 карточки, затем по 20 при скролле вниз). При этом глобальный счетчик базы сразу показывает честную цифру `202`.
* **3D Parallax Cards:** Карточки фильмов интерактивно наклоняются вслед за курсором мыши или пальцем с использованием CSS `perspective` и `transform-style: preserve-3d`. Внутренние элементы (заголовки, кнопки) имеют сдвиг по оси `translateZ`, создавая эффект парящей голограммы.
* **ИИ-Тест «Скан Разума»:** Интерактивный психологический опросник на 4 вопроса, который вычисляет психотип пользователя («Уставший Пилот», «Кибер-Авантюрист») и подбирает терапевтическое кино.
* **Эффект печатающегося текста:** Имитация живых мыслей искусственного интеллекта «Джарвис» при выводе умных рецензий.

### 🎮 Дополнительный интерактив:
* **Кино-Бинго:** Встроенная игра «Найди момент» для параллельного залипания во время сеанса (сбор комбинаций 3х3).
* **Попкорн-Таймер:** Кастомный таймер паузы с неоновым визуальным уведомлением финала.
* **Авиа-пасхалки:** Скрытый трекер строки поиска. При вводе авиационных кодов (`737`, `320`, `airbus`) система воспроизводит бортовой звуковой сигнал приветствия самолета и принудительно включает скрытую янтарную неоновую тему оформления «Airbus Night Flight».

## 🛠️ Архитектура проекта и управление файлами

Проект переведен с онлайн-песочниц в профессиональную среду разработки **Visual Studio Code** и разделен на независимые, чистые JS-модули:
* `index.html` — единая семантическая HTML5 разметка HUD-интерфейса.
* `styles.css` — продвинутые CSS3 стили, переменные неонового свечения (`--neon-color`), лазерные Conic-рамки и медиа-запросы `prefers-reduced-motion`.
* `script.js` — ядро системы, управление вкладками, база данных на 202 фильма и Infinite Scroll.
* `nebula.js` — запуск и оптимизация низкоуровневого WebGL-контекста.
* `radar.js` — отрисовка координатной сетки интерактивного Canvas-радара.
* `cinema-extras.js` — логика игрового Бинго, Таймера, ИИ-теста по психотипам и HUD-руководства.
* `manifest.json` & `service-worker.js` — файлы конфигурации PWA-приложения для кэширования ассетов.

## 🚀 Как запустить проект локально
1. Установите редактор кода **Visual Studio Code**.
2. Поставьте расширение **Live Server**.
3. Склонируйте репозиторий или скачайте ZIP-архив проекта.
4. Откройте папку с проектом в VS Code и нажмите кнопку **Go Live** в правом нижнем углу. Сайт развернется на локальном хосте `http://127.0.0.1:5500`.
